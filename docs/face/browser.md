### 浏览器与网络相关面试题

---

#### 1. 从输入 URL 到页面展示，中间发生了什么？

**答（按阶段概括）：**

1. **URL 解析**：协议、域名、路径、查询串；若是域名则进入 **DNS 解析**（浏览器缓存 → 系统 hosts → 递归 DNS）得到 IP。
2. **建立连接**：TCP 三次握手；HTTPS 还有 **TLS 握手**（证书校验、密钥协商）。
3. **发送 HTTP 请求**：组装请求行、首部、正文；服务器返回响应。
4. **解析响应**：若为 HTML，下载后由 **HTML Parser** 构建 **DOM**；遇到 CSS/JS 按阻塞规则加载与执行。
5. **渲染**：CSS 形成 **CSSOM**，与 DOM 合并为 **渲染树**，**布局（Layout/Reflow）** 计算几何信息，**绘制（Paint）**，合成层 **Composite**（GPU）。

可补充：重定向、强缓存/协商缓存命中则可能跳过网络回源。

---

#### 2. 什么是重排（Reflow）和重绘（Repaint）？如何减少？

**答：**

- **重排**：布局信息变化（宽高、位置、显示隐藏等），需要重新计算布局，开销大。
- **重绘**：外观变化但不影响布局（如 `color`），可能比重排轻，但仍需避免频繁触发。

**减少手段：**

- 批量读写 DOM，避免在循环里交替读布局属性与写样式（强制同步布局）。
- 用 `class` 合并样式变更；`position: absolute/fixed` 脱离文档流减少连锁 reflow。
- 虚拟列表、防抖滚动/resize 回调。
- 能用 `transform` / `opacity` 做动画时优先（常可走合成层，避免大面积 reflow）。

#### 3. 同源策略是什么？跨域有哪些常见解决方案？

**答：**

- **同源**：协议、域名、端口三者一致。
- **同源策略**限制：不同源的页面间 JS 访问、部分存储隔离；**Ajax** 默认不能读跨域响应（浏览器拦截）。

**常见方案：**

| 方案 | 说明 |
| ---- | ---- |
| **CORS** | 服务端返回 `Access-Control-Allow-Origin` 等头；带 cookie 时需 `credentials` 与具体域名配合。 |
| **反向代理** | 开发环境 webpack devServer proxy；生产 Nginx 同源转发，浏览器无跨域。 |
| **JSONP** | 仅 GET，利用 `<script>` 不受同源限制（老方案，新项目少用）。 |
| **postMessage** | 不同窗口/iframe 间通信。 |

#### 4. 强缓存与协商缓存区别？相关 HTTP 头？

**答：**

- **强缓存**：不发请求，直接用本地副本。常见：`Cache-Control: max-age=...`、`Expires`（旧）。
- **协商缓存**：发请求，由服务器决定 304 还是 200。常见：`Last-Modified` + `If-Modified-Since`，或 **`ETag` + `If-None-Match`**（优先级通常更高、更准）。

流程简述：先查强缓存是否未过期 → 过期则带协商头请求 → 304 则读磁盘缓存，200 则更新缓存与页面。

#### 5. `localStorage` 与 `sessionStorage`、`Cookie` 区别？

**答：**

| 项 | localStorage | sessionStorage | Cookie |
| ---- | ------------ | -------------- | ------ |
| 生命周期 | 持久，除非手动删 | 关闭标签页清除 | 可设过期时间 |
| 作用域 | 同源 | 同源 + **同一标签页** | 可设 `domain/path` |
| 容量 | 约 5MB 级 | 约 5MB 级 | 小（约 4KB），每次请求可携带 |
| 与服务器 | 不自动携带 | 不自动携带 | 默认随请求发送（影响带宽） |

#### 6. 什么是 CSP（内容安全策略）？

**答：** 通过 HTTP 头 `Content-Security-Policy` 限制资源加载与执行来源，减轻 **XSS**（如禁止内联脚本、限制 `script-src`）。前端需配合后端配置，违规时浏览器会拦截并上报（若配置了 `report-uri`/`report-to`）。

---

#### 7. 进程与线程？Chrome 多进程架构大致怎样？

**答（简述）：**

- **进程**资源隔离更彻底；**线程**共享进程内内存，更轻量。
- **Chrome** 常见：浏览器主进程、**GPU** 进程、**渲染进程**（站点隔离下多标签页可多个）、**网络**进程、**插件**进程等。前端关注：**渲染进程**里主线程跑 JS、样式、布局；**合成线程**等参与滚动与动画。

---

#### 8. `defer` 与 `async` 脚本区别？

**答：**

| 属性 | 行为 |
| ---- | ---- |
| **async** | 异步下载，**下载完立刻执行**，顺序不保证，适合独立脚本（如统计）。 |
| **defer** | 异步下载，**在 HTML 解析完成后、`DOMContentLoaded` 前按顺序执行**，适合依赖顺序的业务脚本。 |
| 无 | 同步脚本会阻塞 HTML 解析。 |
