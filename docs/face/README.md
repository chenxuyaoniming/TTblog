### 面试题

汇总高频手写与原理题，建议：**先讲思路 → 写代码 → 说边界与复杂度**。

#### 题单（部分）

1. **Promise 并发限流**：控制同时进行的异步任务数量。
2. **Webpack 打包流程**：从入口到 chunk、loader 与 plugin 时机。
3. **Plugin 与 Loader 区别**：Loader 转译模块内容；Plugin 在构建生命周期中扩展行为。
4. **循环引用深拷贝**：使用 `WeakMap` 等记录已访问对象，避免死循环。
