### 算法与数据结构

前端面试与复杂交互（虚拟列表、diff、打包）都会用到基础算法；不必追求竞赛难度，掌握**复杂度分析**与常见题型即可。

#### 复杂度

- **时间复杂度**：大 O 表示法，关注最坏与均摊情况。
- **空间复杂度**：额外使用的内存与递归栈深度。
