### 设计模式

设计模式是面向对象与可维护代码的**可复用方案**，在前端中常见于：事件系统、状态管理、插件架构等。

#### 本站涉及的模式

| 模式 | 要点 | 前端场景举例 |
| ---- | ---- | ------------ |
| **单例** | 全局唯一实例 | 全局配置、日志、弹窗管理器 |
| **观察者 / 发布订阅** | 主题与订阅者解耦 | 事件总线、Redux/Vuex 更新通知 |
| **策略** | 封装可替换算法 | 表单校验规则、支付方式切换 |

#### 学习建议

不必死记类图；重点理解**问题场景 → 模式如何解决 → 在你用的框架里对应什么**（例如 Redux 的 reducer 与单向数据流）。
