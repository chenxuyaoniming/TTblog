### HTML

#### 页面基础

- **语义化**：用 `header`、`nav`、`main`、`article`、`section`、`footer` 等表达结构，利于无障碍与 SEO。
- **文档流**：块与行内、可替换元素；理解默认样式与 CSS 如何覆盖。
- **表单**：`input` 类型、`form` 提交、`label` 与可访问性（`aria-*`）。
