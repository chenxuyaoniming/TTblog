# TTblog 前端知识库

面向日常开发与面试复习的笔记整理，覆盖 **HTTP / HTML / CSS / JavaScript / React / Vue / Webpack / TypeScript** 以及算法、设计模式与面试题。

## 如何使用

- 左侧侧边栏按主题浏览；顶部导航可进入 **学习路线** 与 **个人介绍**。
- 建议顺序：**网络与页面基础（HTTP → HTML → CSS）→ JS 核心 → 框架（React / Vue）→ 工程化（Webpack、TS）→ 算法与设计模式 → 面试题查漏补缺**。

## 内容说明

| 分类 | 说明 |
| ---- | ---- |
| HTTP | 协议、从输入 URL 到页面、状态码 |
| HTML | 事件、缓存、跨页通信等 |
| CSS | BFC、Flex 等布局与基础 |
| JS | 原型、异步、事件、类与模块化等 |
| React / Vue | 虚拟 DOM、生命周期、状态与路由 |
| Webpack | Loader、Plugin 与构建概念 |
| Vite | 新一代构建工具与插件 |
| TypeScript | 类型系统与项目初始化 |
| AI 前端应用 | ChatBot、RAG、Prompt 与 LangChain |
| 数据结构与算法 | 排序、链表、哈夫曼等 |
| 设计模式 | 单例、观察者等 |
| 面试题 | 高频手写与原理题 |
