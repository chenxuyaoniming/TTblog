### HTTP 状态码

状态码在**响应行**中返回，共三位数字，第一位表示类别：**1xx 信息**、**2xx 成功**、**3xx 重定向**、**4xx 客户端错误**、**5xx 服务端错误**。面试常考「含义 + 缓存/SEO 相关行为」。

---

#### 2xx 成功

| 码 | 含义 | 说明 |
| --- | --- | --- |
| **200 OK** | 成功 | 最常见；GET 取资源、POST 提交成功等 |
| **201 Created** | 已创建 | 常用于 POST 创建资源成功，响应常带 `Location` |
| **204 No Content** | 成功无正文 | 删除成功、仅需确认时常用 |

---

#### 3xx 重定向

| 码 | 含义 | 说明 |
| --- | --- | --- |
| **301 Moved Permanently** | 永久重定向 | 资源**永久**换 URL；SEO 权重多会转移到新地址 |
| **302 Found** | 临时重定向 | 历史上实现常不严格；现多用 **303/307** 表达语义 |
| **303 See Other** | 见其它位置 | 应用 POST 后应 **GET** 另一资源时常用 |
| **304 Not Modified** | 未修改 | **协商缓存**命中：客户端带 `If-None-Match`/`If-Modified-Since`，服务端验证未变则返回 304，**无响应体** |
| **307 Temporary Redirect** | 临时重定向 | 方法不变（POST 仍 POST） |
| **308 Permanent Redirect** | 永久重定向 | 类似 301，方法不变 |

**301 vs 302**：永久/临时对浏览器书签、搜索引擎的含义不同；滥用 302 做永久跳转不利于 SEO。

---

#### 4xx 客户端错误

| 码 | 含义 | 说明 |
| --- | --- | --- |
| **400 Bad Request** | 请求无效 | 参数缺省、JSON 格式错等 |
| **401 Unauthorized** | 未认证 | 需要登录或 token 无效（与 403 区分：401 强调「身份」） |
| **403 Forbidden** | 禁止访问 | 已认证但**无权限** |
| **404 Not Found** | 未找到 | 路径或资源不存在 |
| **405 Method Not Allowed** | 方法不允许 | 如对只支持 GET 的接口发了 POST |
| **408 Request Timeout** | 请求超时 | 客户端等待过久 |
| **409 Conflict** | 冲突 | 如版本冲突、重复创建 |
| **413 Payload Too Large** | 请求体过大 | 上传文件超限 |
| **429 Too Many Requests** | 请求过多 | 限流、防刷 |

---

#### 5xx 服务端错误

| 码 | 含义 | 说明 |
| --- | --- | --- |
| **500 Internal Server Error** | 服务器内部错误 | 未捕获异常、代码 bug |
| **502 Bad Gateway** | 网关错误 | 反向代理后面**上游**无响应或非法响应 |
| **503 Service Unavailable** | 服务不可用 | 过载、维护；可配合 `Retry-After` |
| **504 Gateway Timeout** | 网关超时 | 代理等上游**响应超时** |

---

#### 与前端协作要点

- **304**：浏览器可能用**本地缓存**渲染，Network 里体积为 0 或很小。
- **301/302**：前端路由**不会自动改**，是**文档请求**层面的跳转；SPA 首屏若被服务器 301，由浏览器处理。
- 接口调试：先看 **status**，再看 **Response/Headers**，401/403 多为鉴权与权限设计问题。
